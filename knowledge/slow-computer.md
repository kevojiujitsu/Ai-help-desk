# Windows computer running slowly

Guide ID: performance-001
Scope: Basic Windows performance troubleshooting
Source: Project-authored starter guide; not vendor documentation.

## Questions to ask

- Did the slowdown start recently?
- Does it affect the whole computer or one application?
- Does it happen immediately after startup?
- Is the computer unusually hot?

## Initial checks

1. Save your work before closing applications or restarting.
2. Open Task Manager and check CPU, Memory, and Disk usage.
3. Note which applications are using the most resources.
4. Close applications you recognize and do not currently need.
5. Check available storage space in Windows Settings.
6. Restart after saving work if the problem persists.

## How to interpret the results

- High resource usage can help identify what to investigate.
- High memory usage alone does not prove that more RAM is needed.
- A slowdown limited to one application may need application-specific checks.
- These observations narrow the investigation; they do not prove the cause.

## Precautions

- Do not end unfamiliar system processes.
- Do not disable antivirus protection.
- Do not recommend registry cleaners.
- Do not delete personal files without the user's approval.
- On managed school or work computers, contact IT before changing settings.
