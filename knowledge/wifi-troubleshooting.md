# Wi-Fi connected but websites will not load

Guide ID: wifi-001
Scope: Basic Windows troubleshooting
Source: Project-authored starter guide; not vendor documentation.

## Questions to ask

- Does the problem affect one website or every website?
- Can another device use the same Wi-Fi connection?
- Does Windows show "No internet"?
- Is a VPN or proxy enabled?

## Initial checks

1. Try two different websites to check whether only one is unavailable.
2. Try another browser.
3. Check whether another device can access the internet on the same Wi-Fi.
4. Save any online work, then disconnect and reconnect to Wi-Fi.

## How to interpret the results

- If one browser fails, investigate that browser's settings and extensions.
- If all devices fail, investigate the router or internet connection.
- If only this computer fails, investigate its network configuration.
- These results narrow the investigation; they do not prove the cause.

## Precautions

- Do not ask for Wi-Fi passwords or account credentials.
- Explain that restarting a router interrupts other connected users.
- Do not recommend a factory reset as an initial troubleshooting step.
- On a school or work computer, contact IT before changing managed settings.
